# IronMebel — базовый шаблон (HTML, SCSS, JS)

Минимальная структура фронтенд-проекта с использованием **HTML**, **SCSS** и **JavaScript**.

## Структура

- `index.html` — точка входа (разметка страницы).
- `scss/` — исходники стилей (SCSS-модули и отдельные entry-файлы страниц `page-*.scss`).
- `css/style.css` — скомпилированный CSS (не редактировать вручную).
- `js/main.js` — основной JavaScript-файл.
- `package.json` — зависимости и npm-скрипты.

## Установка и запуск SCSS

В корне проекта:

```bash
npm install
```

### Режим разработки (watch)

```bash
npm run dev:sass
```

SCSS из папки `scss/` будет пересобираться в папку `css/` при каждом сохранении.

Основной подход по стилям:
- для каждой HTML-страницы используется свой entry-файл `scss/page-*.scss`;
- каждый такой файл собирается в отдельный `css/page-*.css`;
- в HTML подключается только CSS конкретной страницы;
- `scss/main.scss` и `css/main.css` остаются как общий bundle для редких исключений, когда нужен только shared-набор стилей.

### Продакшен-сборка CSS

```bash
npm run build:sass
```

CSS будет сжат.

## Где писать код

- HTML: `index.html`
- SCSS: shared partial-файлы и отдельные page entry-файлы в папке `scss/`.
- JS: `js/main.js`

После этого достаточно открыть `index.html` в браузере (через Live Server или напрямую из файловой системы).
